# Park Management API

ASP.NET Core Web API project developed for managing park data, visitor operations and park entry fee calculations.

---

## Project Overview

This project was developed as part of a university assignment.

The system allows creation and management of different park types and visitor operations through a RESTful API structure.

The API supports park creation, visitor tracking and park entry fee calculation.

---

## Features

- Create National Park
- Create City Park
- Add visitors
- Remove visitors
- Calculate park entry fee
- Retrieve park information

---

## Technologies

- C#
- ASP.NET Core Web API
- Entity Framework Core
- SQLite
- OOP
- Repository Pattern
